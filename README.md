# Elucidating the evolving mechanisms of PFAS rejection by polyamide membranes under dynamic streams: An adaptive machine learning approach


### Abstract：

Per- and polyfluoroalkyl substances (PFAS) have become one of the most challenging persistent organic pollutants in global aquatic ecosystem remediation due to the high chemical stability and degradation resistance of carbon-fluorine (C-F) bonds. Among various treatment technologies, membrane separation based on polyamide (PA) membranes is considered the most promising method. Machine learning (ML) algorithms are frequently employed to guide the rejection process and predict rejection rates. However, with the drawback of concept drift in ML, traditional ML models are constructed within a static framework and trained on fixed datasets, which limits their ability to capture time-varying feature relationships in the membrane separation process. 
In this study, we developed a two-stage ML workflow for predicting PFAS rejection by PA membranes to address concept drift. A literature-derived static dataset was used to evaluate base-line prediction across different compounds, membrane types, and operating conditions. An inde-pendent, chronologically ordered PFOS/PFBS data stream was used to evaluate prospective model adaptation. The dynamic framework combines sliding-window updating with drift monitoring based on model performance and the Population Stability Index (PSI). Compared with the cor-responding static models, the adaptive models improved prediction performance on the time-ordered data. We also used feature engineering to propose hypotheses about the relative roles of interfacial, size-related, and solution-chemistry factors during membrane operation. This study provides a data-driven tool for predicting time-dependent PFAS rejection by PA membranes. It also provides guidance for designing highly selective PA membranes and optimizing PFAS treatment conditions.


### Keywords: 
Dynamic data stream machine learning; Concept drift; Polyamide membranes; Per- and polyfluoroalkyl substances (PFAS)
